# CNN 数据集说明

图片数据约240 MB（包括重复打包和不同划分），本仓库不携带原课程图片或ZIP。请使用自己有权使用的数据，并按 `cnn-final.py` 的路径准备：

```text
lab5/
  cnn图片/
    train_01/
      类别A/图片.jpg
      类别B/图片.jpg
    val/
      类别A/图片.jpg
      类别B/图片.jpg
    test/
      类别A/图片.jpg
      类别B/图片.jpg
```

三个划分的类别目录应一致，训练、验证、测试数据不应重叠。脚本默认会进行多轮训练，请检查设备选择、轮数与批大小后再运行。
